Что входит в заказ

Профиль: пусто → ✓ на складе → 🔵 в палете → пусто. Когда все профили синие, заказ автоматически считается собранным. Zwrot отмечается отдельно.
Для заказов с профилями статус определяется автоматически по отметкам.
Для старых заказов дата заполняется вручную. Без неё заказ попадёт в группу «Дата выдачи не указана».
Не связана с другими заказами

Запиши количество физических палет и номера остальных заказов, которые лежат вместе с этим. Текущий заказ будет добавлен автоматически. Во всех связанных заказах данные появятся сами.

Через запятую, пробел или с новой строки. Заказы должны уже существовать в базе.

Резервная копия

Данные сохраняются в браузере этого телефона. Регулярно выгружай копию: очистка данных браузера может удалить заказы.

Загрузка копии заменяет текущие данные только после подтверждения. Перед заменой скачай актуальную копию.

Восстановление не затрагивает старую версию сайта, но заменит записи внутри этой версии после подтверждения.

Импорт строк из фотографии
Импорт добавляет отдельную поставку, не заменяя другие доставки и заказы. Если клиент или дата выдачи отсутствуют, их можно дополнить из существующих заказов или исправить вручную. У любой строки (в том числе старой) есть кнопка «⚠ До выяснения» — она отправит строку в общую вкладку проверки.
